## 1. Executive Summary

This report defines the explicit mapping from the raw inference output records in `AI_PORJECT_DATASET/precomputed_evidence/evidence_results.json` (1,157 records) to the verified canonical schema established by Batches 1–3 and enforced by PostgreSQL schema constraints.

## 2. Canonical Evidence Schema Specification

The canonical record structure across Batches 1–3 contains strictly three top-level keys:

```json
{
  "case_id": 1,
  "evidence": {
    "image_evidence": {
      "modality": "Chest X-ray",
      "body_part": "chest",
      "findings": [
        "Cardiac silhouette and mediastinal contours are within normal limits."
      ],
      "abnormalities": [],
      "impression_summary": "No acute cardiopulmonary disease."
    },
    "text_image_consistency": {
      "consistent": true,
      "notes": ""
    },
    "clinical_support": {
      "supported": true,
      "reason": "Dictated findings align with radiographic evidence."
    }
  },
  "raw_model_output": "```json\n{\n  \"image_evidence\": ...\n}\n```"
}
```

### Database Ingestion Target Schema (`models.py`)

| Table | Column | SQL Type | Nullable | Canonical Source Key | Notes |
|---|---|---|---|---|---|
| `cases` | `case_id` | `INTEGER` | `NOT NULL` (PK) | `record["case_id"]` | Native integer identifier |
| `cases` | `classification` | `VARCHAR(50)` | `NOT NULL` | `manifest["classification"]` | "normal" or "abnormal" |
| `cases` | `has_source_text` | `BOOLEAN` | `NOT NULL` | Computed | `False` if empty findings/impression |
| `evidence` | `id` | `INTEGER` | `NOT NULL` (PK) | Autoincrement | Sequence generated by DB |
| `evidence` | `case_id` | `INTEGER` | `NOT NULL` (FK) | `record["case_id"]` | References `cases.case_id` |
| `evidence` | `image_evidence` | `JSONB` | `NOT NULL` | `record["evidence"]["image_evidence"]` | Validated dict |
| `evidence` | `text_image_consistency` | `JSONB` | `NOT NULL` | `record["evidence"]["text_image_consistency"]` | Validated dict |
| `evidence` | `clinical_support` | `JSONB` | `NOT NULL` | `record["evidence"]["clinical_support"]` | Validated dict |
| `evidence` | `raw_model_output` | `TEXT` | `NULLABLE` | `record["raw_model_output"]` | Preserved text or `NULL` |
